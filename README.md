# 进制转换在线考试 - H5网页版使用说明

## 快速预览（本地）

项目已在本地启动预览服务器，打开浏览器访问：

**http://localhost:8080**

即可体验完整功能。

## 功能说明

### 学生端
- 首页：填写学号姓名、查看考试状态、倒计时
- 答题：100道随机题、计时、答题卡、题目标记、自动保存
- 结果：即时得分、正确率、错题分步解析
- 历史：个人历次考试记录与统计

### 教师端
- **入口**：首页连续点击考试标题5次，显示「教师管理入口」
- **默认密码**：admin123（可在配置中修改）
- 考试配置：名称、时间、题量、时长、难度、11种题型权重、密码
- 成绩管理：排名、搜索、三种排序、导出CSV(Excel)、学生详情
- 数据管理：清空数据、全量重置、JSON备份导出

## 部署到线上（让学生扫码使用）

### 方案一：Netlify Drop（最简单，推荐）

1. 打开 https://app.netlify.com/drop
2. 把 `web` 文件夹**直接拖拽**到网页中间的虚线框里
3. 等待几秒，自动生成一个网址，类似 `https://xxx.netlify.app`
4. 这个网址就是你的考试系统地址，学生直接打开就能用
5. （可选）注册一个免费Netlify账号，网址就永久有效，还能自定义名称

### 方案二：Vercel（需要GitHub账号）

1. 注册 GitHub 账号，创建一个新仓库
2. 把 `web` 文件夹里的所有文件上传到仓库
3. 打开 https://vercel.com，用GitHub账号登录
4. 点击「New Project」，选择刚才的仓库，点击「Deploy」
5. 等待部署完成，得到 `https://xxx.vercel.app` 网址

### 方案三：GitHub Pages（需要GitHub账号）

1. 注册 GitHub 账号，创建一个新仓库（建议命名为 `base-exam`）
2. 把 `web` 文件夹里的所有文件上传到仓库根目录
3. 进入仓库 Settings → Pages
4. Source 选择 `main` 分支，根目录，点击 Save
5. 等待1-2分钟，得到 `https://你的用户名.github.io/base-exam/` 网址

## 生成二维码

得到线上网址后，生成二维码给学生扫码：

1. 打开任意在线二维码生成工具（如 https://cli.im 或 https://www.qr-code-generator.com）
2. 把你的网址粘贴进去
3. 点击生成，下载二维码图片
4. 打印出来贴教室，或者直接发群里，学生微信扫码就能答题

## 微信内使用说明

- 学生用微信扫码后，会在微信内置浏览器中打开，直接就能答题
- 不需要关注公众号、不需要下载APP、不需要注册登录
- 数据存储在学生手机浏览器本地，清除微信缓存会丢失数据
- 教师导出的成绩CSV文件可以直接用Excel打开

## 注意事项

1. **数据存储**：H5版数据存在浏览器本地（localStorage），换设备或清除缓存会丢失。建议每次考试结束后及时导出成绩CSV备份。
2. **教师密码**：默认密码 admin123，请首次登录后及时在「考试配置」→「安全配置」中修改。
3. **考试时间**：不设置开始/结束时间时，考试默认为开启状态，学生随时可以进入答题。
4. **多次答题**：默认允许多次答题刷分，成绩按最高分排名。可在配置中关闭。
5. **题型**：共11种转换题型，默认平均分布，可在配置中调整各题型权重。

## 常见问题

**Q: 学生答到一半不小心关了页面怎么办？**
A: 答题进度会自动保存，重新打开网址、填写相同学号后，会提示恢复上次进度。

**Q: 导出的CSV用Excel打开中文乱码怎么办？**
A: 导出的CSV已带UTF-8 BOM头，Excel直接打开应该正常。如果乱码，用记事本打开另存为ANSI格式再用Excel打开。

**Q: 可以自定义题目数量吗？**
A: 可以。教师端 → 考试配置 → 基础配置 → 题目数量，默认100题，可调整为任意数量。

**Q: 怎么调整题目难度？**
A: 教师端 → 考试配置 → 难度配置，可调整基础题/进阶题的数值范围和进阶题占比。
